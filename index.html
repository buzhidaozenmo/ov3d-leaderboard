    方法说明

    收录标准

    面向文本查询的开放词汇 / zero-shot 3D 语义分割方法；在 ScanNet v2、nuScenes 或 Matterport3D 上报告全类 mIoU。类别集合、划分或任务不一致的结果不混入排名。

    排名口径

    只对已核实（verified）的开放词汇行排名，按 mIoU 降序，并列同名次。全监督与少量标签方法同表列出、以横线分隔，不占开放词汇名次。

    数字来源

    优先取原论文表格并记录表号/页码；原论文未报告时转引他文对照表，标「转引自」。同一方法的不同变体拆行，不取平均。

    更新方式

    GitHub Actions 每日 09:00（北京时间）抓取 arXiv / Semantic Scholar / GitHub；新论文进入待审队列，由维护者核对原文后写入榜单并重新部署。
